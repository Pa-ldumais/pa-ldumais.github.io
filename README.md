# 🧠 Solud Makerspace

**Innovating with makers, developers & dreamers.**

A simple, bilingual static website for **Solud Makerspace**, built with plain HTML, CSS, and JavaScript.

## 🌐 Website

**[solud.dev](https://solud.dev/)**

## ✨ Features

* 🇬🇧 English / 🇫🇷 French language switcher
* ☀️ Light mode by default
* 🌙 Dark mode
* Smooth scrolling
* Scroll reveal animations
* Interactive cards and buttons
* Responsive design for desktop and mobile
* No frameworks or dependencies
* GitHub Pages ready

## 🛠️ Built With

* HTML5
* CSS3
* Vanilla JavaScript

## 📁 Structure

```text
.
└── index.html
```

Everything is contained in a single file to keep the site simple and easy to maintain.

## 🚀 GitHub Pages

The site can be deployed directly with GitHub Pages.

Go to:

**Settings → Pages → Deploy from a branch**

Select the branch containing `index.html` and the root (`/`) directory.
